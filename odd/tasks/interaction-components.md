# ODD: In-house interaction components (inspired by Rare UI)

Objective: own versions of the interaction patterns picked from Rare UI, built on MeperPOS tokens, Inter and CSS/WAAPI motion, with no new dependency and no copied code (Rare UI's license requires a visible rareui.com credit for copied components).
Branch: `ui/polish-nov` (worktree `../MeperPOS-worktrees/ui-polish-batch-nov`). Delivery: ask-on-risk. Runner: Vitest. Starts after the current scale sweep and toast work land.

## Specs

- S1 In-place delete confirmation ("delete-button"): destructive row/card actions confirm inside the same control instead of opening `ConfirmDialog`, where the action is reversible or low-stakes; keep the dialog where the server rejects or the consequence is large.
- S2 Animated counter ("animated-counter"): Panel KPI values roll to their new value digit by digit like an odometer; `formatCurrency` output is preserved; `prefers-reduced-motion` shows the value without motion.
- S3 Password input ("password-input"): login and registration password fields get a show/hide toggle; registration adds a strength meter.
- S4 Task list ("task-list"): on Tareas, completing a task strikes it out and moves it to the end of the list with a short transition.
- S5 Theme selector ("theme-selector"): Configuración shows miniature previews of light and dark (and system if supported) with a ring on the selected one.
- S6 Mobile bottom sheet ("family-drawer"): the phone sheets (POS cart drawer, filter sheets) get a drag-to-dismiss bottom sheet with smooth height transitions between views, built without vaul.

It paints the string it is given (the `formatCurrency`/server text is never re-derived), skips all motion on the first render, drops the transition under `prefers-reduced-motion`, and keeps one `sr-only` copy of the full string while the strips stay `aria-hidden`. `MetricCard` got the opt-in `animateValue` prop so the Panel KPIs roll while admin, payroll and reports keep plain values.
- L5 (2026-11-19) T4 / S4 landed: completing a task on `/tasks` draws its title strike-through over 250ms through a `background-size` transition on the text itself (`currentColor` gradient, `data-struck` as the state), then moves the row to the end of the open list with a 300ms FLIP built on `Element.animate` and `getBoundingClientRect` — no library. The row holds its previous slot while the line draws: moving it in the same commit re-inserts the DOM node and kills the CSS transition, so the slot is held in state (render-phase sync, then a release timer). Focus stays on the checkbox of the moved row. Server call, optimistic/rollback path and payload are unchanged; a rejected request leaves the row in place with no strike. `prefers-reduced-motion` draws the line instantly, releases the row at once and skips the transform.
